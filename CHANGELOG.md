# Changelog

## 1.0.0 — 2026-09-27

Первый выпуск.

- Платёжная система Roskassa для модуля «Интернет-магазин» (sale), D7-обработчик `roskassanet`.
- Каждая оплата подтверждается запросом к API шлюза, а не только подписью уведомления.
- Агент сверки раз в 10 минут: быстрый проход по оплатам шлюза за 7 дней и полный обход истории с даты установки. Проводит пропущенные, отмечает двойные оплаты и оплаты без платежа.
- Свой адрес уведомлений с явным ID платёжной системы — не конфликтует с другими обработчиками.
- Адрес шлюза задаётся в настройках (по умолчанию `https://roskassa.net`).
- Блокировка на заказ и журнал оплат (`smoservice_roskassa_credit`): одна оплата шлюза проводится один раз.
- Платёж, который уже снимали с оплаты, повторно автоматически не проводится.
- Номер заказа у шлюза с префиксом (`<префикс>-<ID платежа>`, префикс случайный для каждого сайта): не путается с другими сайтами и интеграциями на том же магазине.
- Тестовые платежи — только в тестовом режиме и только по заказам администраторов.
- Оплата позже 7 суток после создания заказа шлюза автоматически не проводится — ручной разбор.
- API-ключ обязателен: без него форма оплаты не выдаётся.
