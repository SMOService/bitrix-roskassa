# Участие в разработке

Спасибо, что помогаете модулю. Это платёжный код, поэтому требования строже обычного.

## Как предложить изменение

1. Создайте issue с описанием проблемы или идеи — до большого PR лучше договориться о подходе.
2. Форкните репозиторий, создайте ветку от `main`.
3. Внесите изменения и добавьте тесты.
4. Проверьте локально:
   ```bash
   composer install
   vendor/bin/phpunit
   find smoservice.roskassa tests -name '*.php' -print0 | xargs -0 -n1 php -l
   ```
5. Откройте pull request и заполните шаблон.

## Правила для платёжного кода

- **Подпись ≠ оплата.** Любое зачисление подтверждается запросом к API шлюза.
- **Одна оплата шлюза — одно зачисление.** Не обходите журнал `CreditTable` и блокировку `PaymentLock`.
- **Отказ по умолчанию.** Непонятное состояние, ошибка API или сети — это отказ и запись в журнал, а не приём.
- **Суммы — в копейках** (`Money::toMinor`), без сравнения float.
- **Никаких секретов** в коде, тестах, логах и сообщениях об ошибках.
- Код, не зависящий от Bitrix, покрывайте юнит-тестами; код с вызовами ядра держите в `Handler`, `NotifyController`, `Reconciler`, `PaymentLock`.

## Стиль

PSR-12, PHP 7.4+ (без синтаксиса 8.x), комментарии и тексты интерфейса — на русском, языковые файлы — ru и en.
